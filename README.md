# Youtube Trending Analysis

Exploratory data analysis of YouTube trending videos across 10 countries using Python, pandas, and SQL.

## Dataset Source

This project uses the [Trending YouTube Video Statistics dataset](https://www.kaggle.com/datasets/datasnaek/youtube-new) from Kaggle.

The raw data files (`.csv` and `.json`) are not included in this repository due to their size. To run this project yourself, download the dataset from the link above and place the files in the project folder.

## Countries Covered

This dataset includes trending video data for 10 countries:

- US — United States
- MX — Mexico
- GB — Great Britain (United Kingdom)
- IN — India
- JP — Japan
- KR — South Korea
- DE — Germany
- FR — France
- CA — Canada
- RU — Russia

## Tools Used

- Python
- pandas
- Jupyter Notebook
- SQL

## How to Run

1. Download the dataset from the Kaggle link above.
2. Place the `.csv` and `.json` files in the project folder.
3. Open `YOUTUBE_ANALYSIS.ipynb` in Jupyter Notebook.
4. Run the cells in order.
